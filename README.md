# Painel de Inteligência da Cana-de-Açúcar · MS

Conab · Superintendência Regional de Mato Grosso do Sul (SUREG-MS) · SEGEO-MS

Painel público com a produção de cana-de-açúcar, açúcar e etanol de Mato Grosso do Sul (dados oficiais da Conab),
mapa da cana, clima e água no solo por município e logística. O levantamento detalhado aparece ao carregar o arquivo
de dados fornecido pela Conab/MS.

## Publicação (GitHub Pages)
1. Envie `index.html` para a raiz deste repositório.
2. Em *Settings → Pages*, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. O endereço será `https://<conta-ou-organização>.github.io/<nome-do-repositório>/`.

O clima é lido do painel "Levantamento de Safras MS" (rotina diária). Nenhum dado de usina fica no repositório:
**nunca envie para cá as planilhas das usinas nem os arquivos gerados para cada destinatário.**
